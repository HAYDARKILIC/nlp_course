# Week 11 — Modern LLM Applications: RAG, Tools, Evaluation

> Beyond the model: the systems and evaluation frameworks that make LLMs useful in practice. Retrieval-augmented generation, tool use, and modern evaluation harnesses.

## Learning Objectives

- Build a retrieval-augmented generation (RAG) pipeline from scratch — embedding, indexing, retrieval, generation.
- Implement structured tool calling and explain its relationship to in-context learning.
- Use modern evaluation harnesses (lm-evaluation-harness) and discuss their limitations.
- Discuss the contamination problem in LLM benchmarks.

## Required Reading

- Lewis, P., et al. (2020). *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*.
- Karpukhin, V., et al. (2020). *Dense Passage Retrieval for Open-Domain Question Answering*.
- Liang, P., et al. (2022). *Holistic Evaluation of Language Models*.
