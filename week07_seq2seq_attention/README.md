# Week 7 — Sequence-to-Sequence and Attention

> The encoder–decoder paradigm and the attention mechanism that broke its bottleneck. This is the conceptual bridge to the Transformer.

## Learning Objectives

- Implement an LSTM-based seq2seq model for neural machine translation.
- Identify the information-bottleneck problem of vanilla seq2seq.
- Derive and implement Bahdanau (additive) and Luong (multiplicative) attention.
- Visualize attention heatmaps and interpret them linguistically.

## Required Reading

- Sutskever, I., Vinyals, O., & Le, Q. V. (2014). *Sequence to Sequence Learning with Neural Networks*.
- Bahdanau, D., Cho, K., & Bengio, Y. (2015). *Neural Machine Translation by Jointly Learning to Align and Translate*.
- Luong, M.-T., Pham, H., & Manning, C. D. (2015). *Effective Approaches to Attention-based Neural Machine Translation*.
