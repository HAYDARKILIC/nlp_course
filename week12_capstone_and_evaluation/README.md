# Week 12 — Capstone: End-to-End Domain-Specific Language Model

> Bring it all together. Each student picks a domain (legal, medical, scientific, code, or low-resource language) and delivers an end-to-end pipeline: data collection, tokenizer training, pretraining or continued pretraining, fine-tuning, evaluation, and a short report.

## Learning Objectives

- Design and execute an end-to-end NLP project on a domain of your choice.
- Make principled decisions about tokenizer, architecture, training data, and evaluation.
- Write a research-style report on the results, including ablations and failure analysis.
- Defend the work in a 15-minute presentation.
